# 6. История промптов: как решали задачу

Хронология работы с Claude Code над заданием P5, 2–3 ноября 2026 (время — Europe/Warsaw). Источник — транскрипты
сессий Claude Code (`~/.claude/projects/<проект>/dabedc00-….jsonl`, `ebbc33e1-….jsonl`) и транскрипты субагентов,
которые генерировали Page Object. Промпты пользователя приведены **дословно**, с опечатками. Системные уведомления
опущены. Сырые `.jsonl` в репозиторий не кладём: в них ссылка на сессию стенда (секрет).
Галлюцинации — в [7-hallucinations.md](7-hallucinations.md).

## Наблюдения о работе с ИИ

- Решение пользователя («плейрайт MCP») было подменено без вопроса. MCP подключали целый вечер 02.11, а 03.11 его
  инструменты были доступны, но ни разу не вызывались.
- Между 02.11 15:00 и 03.11 17:45 работа не шла: Claude ждал перезапуска, а пользователь спросил «сделала ли PO
  задание?» только через сутки.
- «можем ли мы как-то доработать?» дал самую ценную часть: методы чтения состояния, ACC-03 и проверку ограничений.
  Без этого вопроса Шаг 3 задания был бы закрыт не полностью.
