# 4. Verify — прогоны до/после

> «Починен» = 0 целевых падений из 30 в каждом обязательном условии + проходит repro + падает в негативной
> проверке ([критерии](1-research.md#1-критерии)). Прогоны «до» и «после» чередуются блоками в одной сессии, чтобы
> состояние стенда не исказило сравнение.

## 1. Прогоны

Определения `$SK`, `$RC`, `${META[@]}`, `${PW[@]}` — в [профиле](../../.flaky/profile.md). Код «до» — в
`git worktree` на исходном коммите, «после» — рабочая ветка.

```bash
# блоки чередуются: before 1 → after 1 → before 2 → after 2
$RC after base --block 1 "${META[@]}" -- "${PW[@]}" --project=flaky --repeat-each 10 --workers=1

node $SK/scripts/flaky-stats.mjs --threshold 30 \
  before:base=deliverables/flaky/runs/<...>_before_base_1.json after:base=deliverables/flaky/runs/<...>_after_base_1.json ...
```

## 2. Результат

_Таблица `flaky-stats`: тест × условие → прогонов / pass / fail (целевые) / fail (шум) / % до → % после / починен._
